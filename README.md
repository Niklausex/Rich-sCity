# Rich's City 🧱 乐高市长模拟游戏

## 项目概览
- **名称**: Rich's City
- **目标**: 为小学三年级孩子打造的"寓教于乐"城市模拟经营游戏。孩子扮演市长，通过回答学科题目赚取城市收入，规划建设自己的乐高风格城市，从小村庄一路发展为超级城市。
- **玩家**: 单人（本地浏览器存档，自动保存）

## 已完成功能 ✅
1. **开局设定**：100元资金 + 木质市长办公室 + 停车位，8位初始家人居民（爸爸/妈妈/奶奶/爷爷/姥姥/姥爷/小姨/哥哥）
2. **答题系统**：每天3~5位居民随机提问，覆盖 数学(程序生成)/语文/英语/科学/通识 五科；答对得零花钱+居民升级经验，答错显示知识点讲解；题目难度可在设置中按年级(3~6)调整
3. **居民成长线**：12级职业头衔（见习居民→快递员→…→宇航员），等级越高周薪越高
4. **经济系统**：每7天可收税一次 = 居民工资10% + 商业营业额10%；幸福度影响商业消费热情(0.5x~1.5x)
5. **建造系统**：59种建筑，五大类（商业/公共/住宅/配套/🌳装饰14种小物），自由摆放、旋转、移动、命名、拆除(退一半)；**每周城市收入达标解锁高级建筑**（0→150→220→…→8000元/周共17档）
6. **城市地图 (v3.0 美术贴图版)**：等距 2.5D Canvas 渲染，**52张用户自制美术贴图**（45建筑+8家人，已抠图转WebP，125MB→2.6MB）；居民地图上行走(向右镜像翻转+摇摆动画)、汽车沿道路行驶、飞机飞过天空；拖拽平移、滚轮/按钮缩放、触屏操作；道路由代码绘制(无缝拼接)
7. **居民装扮**：解锁12款帽子（皇冠/博士帽等，地图上可见）；上衣/裤子颜色仅对无贴图的居民生效
8. **住宅房租**：6种住宅每周产生房租收入（木屋15元/周 → 摩天住宅680元/周），是提升周收入的稳定来源
   - ⏸️ *招募新居民功能本版本关闭（固定8位家人）；24位候选角色与代码全部保留，把 `CATALOG.RECRUIT_ENABLED` 改成 `true` 即可重新开启*
9. **车辆收藏**：39款参考真实车型/机型（五菱MINI EV、特斯拉Model 3、复兴号、C919、A380、山东舰航母、长征五号等），火车/飞机/轮船/火箭需先建对应设施
10. **礼物系统**：同一居民连对10/20/30/50/100题送实物兑换卡（小汽车玩具卡等），可在礼物盒兑换后找家长领取实物
11. **城市等级**：小村庄→小镇(250)→大镇(600)→城市(1200)→大城市(2500)→超级城市(5000)（按每周城市收入）
12. **天数循环**：睡觉进入新一天，刷新居民问题；市政厅有成绩单和城市日志
13. **本地存档**：localStorage 自动保存，可重置

## 数据架构
- **存储**: 浏览器 localStorage（键 `richs_city_save_v1`），单玩家无需后端数据库
- **数据模型**: 城市状态(资金/天数/快乐值) + 居民数组(等级/经验/连对/装扮) + 建筑数组(类型/坐标/名字) + 车辆/装扮/礼物清单
- **题库**: `questions-data.js` 基础静态题库 + `questions-data2.js` 扩容题库（英语分级词汇表 + 科学/通识/英语 约 208 道）+ `questions-data3.js` v3.4 课程包（牛津树/YLE 词汇并入后共 **374 词**（g3:89/g4:101/g5:96/g6:88）+ 英语阅读 24 + 美式通识 50 + 科技科学 32 + 语感鉴赏 28 + 创作题 16 + 跟读短文 15）+ `questions.js` 生成器（数学计算/逻辑思维 11 类 + 英语词汇 5 类 + 听音选词，可组合出上千道不重复题）
- **TTS**: 浏览器内置 speechSynthesis（en-US），零成本零联网依赖；听音题自动播放，跟读支持慢速 0.72x / 正常 0.95x
- **每日答题**: 每位居民每天上限 **50 题**，答完一题可点「再来一题」继续；科目按权重抽取：英语30% / 科学25% / 通识25% / 数学12% / 语文8%
- **学习闭环 v3.4**: 答对 → 进入"已掌握"不再作新题出现，同时进入**遗忘曲线巩固队列**（7 天后约 20% 概率巩固复习一次 🔁，再对才算真掌握）；答错 → 进入**错题本**，约 30% 概率优先复习（📖 徽标，选项重洗防背位置）答对才移出；听音/创作等题面雷同的题用 `qkey` 区分去重

## 使用指南（给小市长）
1. 每天点左侧「居民」，回答居民问题——答对赚钱、居民升级；每位居民每天最多可答 50 题，答完一题可以接着「再来一题」
2. 每7天去「市政」收税（居民税+商业税）
3. 用钱在「建造」里买建筑，点击地图放置，可以命名和移动
4. 多建公园/学校提升幸福度 → 商业挣更多 → 税收更多
5. 多建商铺和住宅提高「每周城市收入」，周收入越高解锁的建筑越高级（居民答题升级也会涨工资、涨周收入）
6. 攒钱去「车库」解锁真实名车、高铁、大飞机、航母！
7. 连续答对10题，居民会送你实物玩具兑换卡 🎁
