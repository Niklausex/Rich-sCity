## 0. 通用规范（所有素材都要遵守）

| 项目 | 要求 |
|------|------|
| 风格 | 与已交付的 52 张一致：**Q 版 3D 软胶玩偶 / 黏土微缩景观质感**（chibi vinyl toy, smooth clay render）/ 明亮饱和 / 圆润厚实 / 无描边 / 儿童向，无写实照片感 |
| 视角 | **等距 3/4 视角**：方位角 45°、俯角约 30°（和现有建筑贴图同一视角，能对齐菱形地块） |
| 光照 | 光源固定在**左上方**，右侧和下方为阴影面；**不要画地面投影阴影**（引擎会自动画椭圆阴影） |
| 背景 | **纯透明 PNG**（不要白底、不要渐变底、不要边框、不要文字水印） |
| 构图 | 主体**底部贴边、左右居中**，四周不留多余透明空白（我会再裁一遍，但尽量贴边） |
| 分辨率 | 建筑/车辆：短边 ≥ 1024px；角色/道具：≥ 768px；图标：512px |
| 文件名 | 必须用下表的 **英文 id**，小写+下划线，例：`char_baker_wang.png`、`veh_wuling.png` |
| 一次一张 | 每个 id 一张独立文件，**不要拼图/九宫格**（拼图我需要手工切，容易错位） |

### 视角对齐小抄
- 建筑：想象把黏土微缩模型放在桌上，从**左前上方 45°** 看，正面朝左下（转角朝观众）。
- 角色：站姿、身体朝**左下方** 3/4 侧身（与现有 8 位家人一致，向右走时引擎自动镜像）。
- 车辆：车头朝**左下方**，能看到车头+左侧车身（和角色朝向一致）。

## 2. ⭐ P0 当前最高优先：地面贴图（4 张，性价比最高）

草地和道路现在都是纯代码画的色块，是画面里最"廉价"的部分。**只需要 4 张"单格菱形材质图"**，路口标线、虚线、拼接方向由引擎自动画在上面（所以不要在图里画方向性的标线，否则转弯处会歪）。

- 尺寸：**1024 × 512**（宽:高 = 2:1 的菱形，菱形 4 个尖角刚好顶到图片 4 条边的中点）
- 菱形以外的区域必须**完全透明**
- **不要画任何标线/箭头/车/树/人**，只要"材质"

| `ground_grass.png` | 草地菱形 | 明亮饱和的短草坪质感，可无缝平铺 |
